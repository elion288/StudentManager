# Student Manager

This is a small C# console project I made to practice programming.

With this program, I can add students, search for them, edit their information and delete them. I also added options to show the best student and calculate the average grade of the students.

I used JSON to save the students and their data so they don't disappear when I close the program.

I built this project to improve my C# skills and practice what I've learned.
